# 生日小屋

一个在本地运行的温馨卡通 3D 生日寻宝 demo。使用 React、Three.js 和 Vite；家具、植物、小猫、蛋糕均为程序化 3D 模型，无需外部图片或模型服务。

当前版本采用简笔画式 2D 动漫画风：平涂色块、三档明暗与深色轮廓线，保留第一人称自由行走。房间由约 8.5 × 6.8 扩大到 12.5 × 10.8 个场景单位，家具保持原有尺寸，新增阅读桌、挂钟、明信片和绿植工作台。

## 启动

```powershell
npm.cmd install
npm.cmd run dev
```

打开终端显示的本地地址，通常是 http://127.0.0.1:5173 。本项目需要通过本地服务器打开，不能直接双击 index.html。

```powershell
npm.cmd run build
npm.cmd run preview
```

## GitHub Pages 发布

自动发布配置位于 `.github/workflows/deploy.yml`。首次发布需在目标仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。

将项目源文件、`public/`、锁文件和工作流推送至 `main` 或 `master` 后，Actions 会安装依赖、检查谜题逻辑、构建并发布 `dist/`。无需上传 `node_modules/`、`dist/` 或本地测试截图。发布地址以 Actions 的 `github-pages` 环境输出为准，通常为 `https://<账号>.github.io/<仓库名>/`。

构建使用相对资源路径，包含奶酪体字体，兼容 GitHub Pages 的仓库子目录。网站访问者不需要启动本地服务器；探索进度仍单独保存在每台设备的浏览器中。

## 玩法

- 点击「走进小屋」，以人眼高度进入封闭 3D 房间。WASD 行走，鼠标转头；Esc 释放鼠标。
- 走近家具，对准后按 E 或点击浮现的小圆点，互动提示显示在左下角（手机位于方向键上方），发现并拆开五份生日礼物。物品有距离和遮挡检查。
- 点击「一点提示」获得线索；「口袋里的心意」中可以查看已收集的祝福。
- 点击「手记」回看找到的线索与道具。五份礼物分别需要解开书架排序、时间密码、浇水、钥匙锁和旋律机关；错误操作可以重试。
- 门旁有实体灯光开关，走近后点击或按 E，可开关室内灯光。关灯后保留窗外月光，仍能看清家具与通路。
- 中央茶几的蛋糕起初被礼物盒完整罩住；五份礼物未收齐时，互动会提示剩余数量。收齐后再次互动，盒盖抬起、盒身展开淡出，蛋糕渐渐显露，视线缓缓转向蛋糕。
- 揭盒时室内灯光渐暗，窗外切换为月夜，淡蓝色月光与窗格光斑照入房间，家具仍可辨认；蛋糕附近保留摇曳的暖色烛光。旁边的唱片自动播放《祝你生日快乐》八音盒纯音乐，并随音乐旋转；无需提前开启音乐。出场动画期间暂停行走，结束后显示许愿面板。可在许愿和祝福窗口暂停或重新播放。
- 吹灭蜡烛后，室内灯光重新亮起。关闭许愿面板也可以继续在烛光中探索，再到门边开灯。礼盒揭开状态随进度保存，重新探索会把礼盒合上、灯光和音乐重置。
- 生日曲播放一遍后停止，可再次打开蛋糕重播。关闭祝福窗口不会中断音乐；重新探索会停止音乐并重置。刷新页面不会自动发声。
- 点击小猫会得到一条特别留言。右上角可打开本地合成的八音盒音乐。
- 也可按住画面拖动转头，上下方向键前后走，左右方向键转头。手机横屏使用：左侧方向按钮行走、滑动转头、右侧互动按钮；竖屏会显示旋转手机提示并暂停行走，转回横屏后继续当前进度。互动提示不再显示键盘按键 E。
- 弹窗打开、窗口失焦时会停止移动。进度保存在当前浏览器，刷新保留；口袋中可重新探索，回转箭头只重置位置。

## 后续修改位置

- `src/content.js`：收礼人名字、五位朋友的名字、礼物名称、线索、祝福。
- `src/room.js`：3D 房间、家具、灯光、相机和物品交互位置。
- `src/main.jsx`：游戏流程、收藏、许愿和界面。
- `src/style.css`：奶油色与鼠尾草绿视觉、桌面与手机布局。
- `src/audio.js`：本地合成八音盒配乐。
- `src/birthday-score.js`：《祝你生日快乐》主旋律与伴奏音符。
- `src/walking.js`：人物碰撞半径、家具占地和移动碰撞。
- `src/first-person.js`：鼠标、键盘、触屏与第一人称相机控制。
- `src/first-person.css`：全屏场景、探索界面和触屏操作。
- `src/puzzles.js`：谜题条件、答案校验、道具、线索和渐进提示。
- `src/PuzzlePanel.jsx` 与 `src/puzzles.css`：谜题操作界面与手记。
- `src/doodle.css`：简笔画描边与平涂 UI。
- `src/handwriting.css`：本地手写字体、字号与生日音乐控件。
- `src/mobile-landscape.css`：手机横屏布局、横屏许愿面板和旋转手机提示。

界面与房间标牌采用郑庆科设计的「小可奶酪体 / ZQKNLT」，[作者发布页](https://www.zcool.com.cn/work/ZNjA5MDU2NTI=.html)声明商用免费。网页字体从 [ZeoSeven Fonts](https://fonts.zeoseven.com/items/242/) 下载至 `public/fonts/cheese/`，保留完整字库的分片，按出现的文字加载，运行时无需连接字体服务。来源与作者声明记录见 `public/fonts/cheese/NOTICE.txt`。生日纯音乐由浏览器合成，没有人声，不需要外部音频服务。

当前人物名字与祝福均为可替换的 demo 内容。场景使用第一人称透视相机，固定眼高 1.85 米，有房间边界与家具碰撞。鼠标锁定不可用时，仍可拖动转头和按键行走。没有跳跃、楼层或多人联机。

解谜版本使用独立的 `birthday-little-room-v2` 浏览器存档，保留旧版本存档，第一次进入从新机关开始。刷新会保留机关状态、已取得的道具、手记与礼物；只有「重新探索」会重置本版本进度。

## 本地验证

开发服务器启动后，在 Windows 上使用已安装的 Microsoft Edge 执行：

```powershell
node scripts/check-demo.mjs
```

验证碰撞、所有礼物位置的可达性、实际 WASD 行走收集五份礼物、E 互动、弹窗暂停、刷新存档、许愿、音乐和触屏移动与松手停止。截图写入 `test-results/`。其他系统可修改脚本中的浏览器路径。

`node scripts/check-puzzles.mjs` 可单独验证谜题的正确与错误答案、道具前置条件、奖励不重复、保存恢复，以及扩大后房间的通路。

`node scripts/check-birthday.mjs` 验证手写字体、礼物数量门槛、打开蛋糕自动播放、暂停重播、唱片同步、自然结束与重新探索；同时检查实际音频合成、重复触发不叠音及手机布局。

`node scripts/check-reveal.mjs` 验证实体开关、礼盒解锁门槛、揭盒动画期间暂停行走、烛光许愿、恢复行走、揭盒存档、吹灭蜡烛后亮灯、重置、手机布局和减少动态效果。

## 技术要求

`node scripts/check-landscape.mjs` 验证手机竖屏提示、旋转后暂停与恢复、横屏触屏移动，以及 844 × 390 和 667 × 375 下的控件布局。

使用支持 WebGL 2 的现代浏览器，建议开启硬件加速。安装依赖需联网，安装后运行及游戏内容不依赖外部网络服务。系统减少动态效果设置会关闭装饰动画。
